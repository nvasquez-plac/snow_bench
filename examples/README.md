# Examples of configuration files and scripts to evaluate experiments

## Information 
This directory contains examples of configuration files and scripts for the users. When the user is carrying out a new evaluation, they needs to have a configuration file and the corresponding evaluation script in a given directory, separated from the evaluation package. 

## Files

**config_svs2_era5L.py**

* Example of configuration file to evaluate a SVS2 experiment against a benchmark from ERA5L. 
* This file contains all the information about the different experiments (see the file for model details)

**run_eval.sh**

* Script to run the different steps of the snow evaluation  
* Script corresponding to the configuration file `config_svs2_era5L.py`
